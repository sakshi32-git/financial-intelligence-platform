# Global Financial Intelligence Dashboard

## Goal

Build an enterprise-grade Financial Analytics Platform.

The project must demonstrate:

- Python
- SQL
- PostgreSQL
- ETL
- API Integration
- Data Cleaning
- Data Analysis
- Statistics
- Machine Learning
- Dashboard
- Deployment

---

## Development Principles

- Never generate the whole project in one prompt.
- Complete only one small task per prompt.
- Keep prompts under 150 lines.
- Every module must be independently testable.
- Every module must run before moving to the next.
- No placeholder code.
- No TODO comments.
- Use production-quality code.
- Follow PEP8.
- Modular architecture only.
